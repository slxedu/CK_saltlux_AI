로그인 따라 하기

아래 순서대로 진행하면 교육용 계정 로그인을 완료할 수 있습니다.

Claude Desktop 다운로드 ↗ Claude 로그인 페이지 ↗
!
로그인 전 꼭 확인해 주세요

기존 개인 Claude 계정이 로그인되어 있다면 모두 로그아웃한 뒤, 안내된 교육용 실습 계정으로 로그인해 주세요.

오전반실습계정 배정표 열기↗ 오후반실습계정 배정표 열기↗
1
START

Claude Desktop에서 시작하기

Claude Desktop 앱을 실행하고 시작하기를 누릅니다. 앱을 설치하지 않았다면 상단의 다운로드 버튼을 먼저 이용해 주세요.

2
ACCOUNT LIST

오전반·오후반 배정표 확인

본인 수업 시간에 맞는 배정표를 열고, 본인에게 배정된 교육용 이메일과 개인 PIN을 확인합니다.

오전반배정표 바로가기↗ 오후반배정표 바로가기↗
계정과 PIN은 본인에게 배정된 정보만 사용해 주세요.이메일은 오타 방지를 위해 직접 입력하지 말고 복사·붙여넣기 하는 것을 권장합니다.
3
EMAIL LOGIN

교육용 이메일로 계속하기

Claude 로그인 화면에 배정표에서 확인한 교육용 이메일을 붙여넣고 이메일로 계속하기를 누릅니다. Google로 계속하기는 선택하지 않습니다.

4
MAILBOX

로그인 메일함 열기

로그인 메일함 사이트에서 배정된 교육용 이메일과 개인 PIN을 입력한 뒤 내 메일함 열기를 누릅니다.

Claude 로그인 메일함내 메일함 열기 ↗
PIN은 교육용 이메일의 비밀번호가 아닙니다.로그인 메일함을 확인하기 위한 개인 확인 번호이며, 배정표에서 확인할 수 있습니다.
5
LATEST MAIL

가장 최근 인증 메일의 본문 보기

메일함에서 가장 최근에 도착한 Anthropic 로그인 메일을 찾고 본문 보기를 누릅니다.

메일이 아직 보이지 않나요?메일 새로고침을 눌러 주세요. 새 메일은 약 20초 간격으로 반영될 수 있습니다.
6
CONTINUE

Claude 로그인 계속하기

열린 메일 본문에서 파란색 Claude 로그인 계속하기 버튼을 누릅니다.

7
OPEN APP

브라우저 팝업에서 Claude 열기

새로 열린 브라우저에서 앱 실행 팝업이 나타나면 Claude 열기를 선택합니다.

8
COMPLETE

교육용 계정 로그인 완료

Claude Desktop이 열리면 화면 왼쪽 아래에서 교육용 계정으로 로그인되었는지 확인합니다.

Claude 실습 준비 완료이제 교육 실습에 참여할 수 있습니다.
