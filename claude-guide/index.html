INSTALL

먼저 Claude Desktop을 설치하세요

로그인 전에 다운로드 페이지에서 본인 PC 운영체제에 맞는 앱을 설치합니다.

Windows 사용자Windows용 다운로드
Mac 사용자macOS용 다운로드
claude.com/download 열기 ↗

아래 로그인 절차를 시작하기 전에 앱 설치를 먼저 완료해 주세요.

1
COPY & PASTE

안내받은 실습계정을 복사·붙여넣기

본인에게 안내된 실습계정 이메일을 복사해 Claude 로그인 창에 붙여넣은 뒤 이메일로 계속하기를 누릅니다.

오전반실습계정 배정표 열기↗ 오후반실습계정 배정표 열기↗
직접 타이핑하지 마세요.철자나 숫자 오타를 막기 위해 반드시 복사·붙여넣기 합니다. 개인 이메일을 로그인 칸에 넣으면 안 됩니다.
2
VERIFY

‘인증 코드 입력’을 누르세요

로그인 링크 안내 화면이 나오면 인증 코드 입력을 선택합니다. 다음에 나타나는 6자리 코드 입력창은 닫지 말고 그대로 열어두세요.

3
EMAIL

개인 이메일을 확인하세요

로그인 인증번호를 받는 본인 이메일에서 Anthropic의 로그인 보안 메일을 열고 로그인 버튼을 누릅니다.

메일 수신까지 최대 3분 정도 걸릴 수 있습니다.바로 오지 않아도 재전송을 반복하지 말고 2~3분 기다린 뒤 다시 확인해 주세요.
인증메일이 여러 개라면 가장 최근에 받은 메일을 사용해 주세요.
4
BROWSER

팝업이 나타나면 ‘열기’를 누르세요

브라우저가 Claude 앱 실행 여부를 물으면 열기를 누릅니다. Claude Desktop 앱이 자동으로 열리면서 로그인이 진행됩니다.

팝업에서 ‘열기’를 선택하세요.
앱이 자동으로 열리지 않나요?화면 아래의 코드로 로그인을 누른 뒤, 아래 예외 안내에 따라 6자리 코드를 복사·붙여넣기 하세요.
예외
EXCEPTION

자동으로 열리지 않을 때: 6자리 코드 입력

4번에서 앱이 정상적으로 열렸다면 이 예외 안내는 건너뜁니다. 열리지 않은 경우에만 코드로 로그인을 누르고,
브라우저에 표시된 6자리 코드를 복사해 2번에서 열어둔 Claude Desktop 인증 코드 입력창에 붙여넣기 합니다.

설치 및 로그인 준비 완료이제 교육 실습에 참여할 준비가 끝났습니다.
