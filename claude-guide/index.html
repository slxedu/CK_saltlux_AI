INSTALL

Claude Desktop 앱 설치

다운로드 페이지에서 본인 PC 운영체제에 맞는 버전을 내려받아 설치합니다.

Windows 사용자Windows용 다운로드
Mac 사용자macOS용 다운로드
claude.com/download 열기 ↗

아래 로그인 절차를 시작하기 전에 앱 설치를 먼저 완료해 주세요.

1
ACCOUNT

Claude 실습계정 로그인

Claude 앱 로그인 화면에서 본인에게 배정된 실습계정 이메일을 입력한 뒤 이메일로 계속하기를 클릭합니다.

예시: saltluxedu00@saltlux.com

2
VERIFY

반드시 ‘인증 코드 입력’ 선택

로그인 링크 안내 화면에서 인증 코드 입력을 선택합니다. ‘이메일 재전송’이나 ‘다른 이메일 사용’을 누르지 마세요.

3
WAIT

인증 코드 입력창 열어두기

6자리 인증코드 입력 화면을 그대로 열어둔 상태에서, 사전에 등록한 로그인 코드 수신용 개인 이메일을 확인합니다.

메일 수신까지 최대 3분 정도 걸릴 수 있습니다.메일이 바로 오지 않아도 재전송을 반복하지 말고 2~3분 기다린 뒤 다시 확인해 주세요.
4
EMAIL

개인 이메일에서 Anthropic 로그인 메일 확인

개인 이메일에서 Anthropic이 발송한 Claude.ai 로그인 보안 링크 메일을 열고 본문의 로그인 버튼을 클릭합니다.

인증메일이 여러 개라면 가장 최근에 받은 메일을 사용해 주세요.
5
BROWSER

앱 실행 취소 → ‘코드로 로그인’ 선택

브라우저가 Claude 앱 실행 여부를 물으면 취소를 누릅니다. 이어서 화면 하단의 코드로 로그인을 선택합니다.

‘Claude 열기’를 누르지 마세요.반드시 취소 후 코드로 로그인을 선택합니다.
6
FINISH

표시된 인증코드를 3번 화면에 입력

‘코드로 로그인’을 선택하면 6자리 인증코드가 표시됩니다. 코드를 복사한 뒤 앞서 열어둔 3번의 인증 코드 입력 화면으로 돌아가 입력합니다.

설치 및 로그인 준비 완료이제 교육 실습에 참여할 준비가 끝났습니다.
